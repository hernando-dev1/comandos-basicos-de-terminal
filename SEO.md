# Relatório de SEO — Atividade 2

**Projeto:** Comandos Básicos de Terminal  
**Disciplina:** Linguagem de Script para Web — IFTM  
**Data das alterações:** 26/11/2026

## 1. Palavras-chave escolhidas

- **comandos básicos de terminal** — termo principal da página inicial.
- **comandos Linux para iniciantes** — expressão relacionada ao público e ao conteúdo.
- **aprender a usar o terminal** — intenção informacional de quem está começando.

As palavras-chave foram distribuídas naturalmente entre títulos, descrições e conteúdo. Não foram repetidas artificialmente.

## 2. Decisões de otimização

- Cada página recebeu `title`, `meta description` e URL canonical próprios.
- Foram adicionadas propriedades Open Graph e Twitter Card para compartilhamento.
- Foi criado um favicon SVG.
- A página inicial utiliza dados estruturados `TechArticle`; a página institucional utiliza `AboutPage`.
- Foram criados `robots.txt` e `sitemap.xml` na raiz do projeto.
- Os links internos usam textos descritivos e conectam `index.html` e `sobre.html`.
- As imagens de conteúdo foram convertidas para WebP, receberam texto alternativo, dimensões explícitas e carregamento tardio nas imagens que não aparecem inicialmente.
- Foi criada uma imagem Open Graph de 1200 × 630 pixels.

## 3. Validação

- JSON-LD: validar as URLs publicadas em https://validator.schema.org/.
- Lighthouse: executar em modo **Mobile**, nas categorias Performance, Accessibility, Best Practices e SEO.

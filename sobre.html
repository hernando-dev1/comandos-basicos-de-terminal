A proposta

O projeto Comandos Básicos de Terminal foi desenvolvido para apresentar, de forma simples e prática, alguns comandos utilizados no terminal Linux.

O conteúdo é voltado a pessoas que estão começando a utilizar a linha de comando e desejam conhecer operações comuns de navegação, listagem de arquivos e gerenciamento de permissões.

O que você encontra aqui

  • Exemplos de navegação entre diretórios com cd;
  • Listagem de arquivos e pastas com ls;
  • Noções de permissões com chmod;
  • Uma tabela de referência rápida com comandos úteis.

Contexto acadêmico

Este é um projeto desenvolvido por Hernando Procópio de Souza Almeida para a disciplina Linguagem de Script para Web, do Instituto Federal do Triângulo Mineiro (IFTM), Campus Uberaba Parque Tecnológico.

As páginas foram organizadas para facilitar a navegação, a leitura em dispositivos móveis e o compartilhamento dos conteúdos.
